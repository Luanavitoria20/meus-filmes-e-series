# 🎬🍿 Meus Filmes e Séries

Bem-vindo(a) ao **Meus Filmes e Séries**! 🎥✨

Este projeto foi desenvolvido com o objetivo de reunir filmes e séries em um só lugar, apresentando informações sobre diferentes produções do mundo do entretenimento. A proposta é criar uma experiência visual agradável, organizada e fácil de utilizar.

O projeto também faz parte da minha jornada de aprendizado e desenvolvimento na área de tecnologia, permitindo colocar em prática conhecimentos de desenvolvimento web.

## 🌟 Sobre o projeto

O **Meus Filmes e Séries** é um site dedicado aos amantes de cinema e televisão. A ideia é facilitar a visualização de informações sobre filmes e séries, com uma interface intuitiva e organizada.

## 🚀 Funcionalidades

- 🎞️ Exibição de filmes e séries.
- 🖼️ Apresentação de capas e imagens das produções.
- 📅 Informações sobre o ano de lançamento.
- 🎭 Identificação dos gêneros.
- 🔗 Links relacionados às produções.
- 💻 Interface desenvolvida para facilitar a navegação.

*Observação: as funcionalidades descritas devem corresponder aos recursos efetivamente implementados no projeto.*

## 🛠️ Tecnologias utilizadas

- 🌐 **HTML5** — estruturação das páginas.
- 🎨 **CSS3** — estilização, cores, layout e responsividade.
- ⚡ **JavaScript** — implementação de interatividade e manipulação dos elementos da página.
- 🐙 **Git e GitHub** — versionamento e armazenamento do código-fonte.

## 💻 Como executar o projeto

1. Acesse o repositório no GitHub.
2. Faça o download do projeto ou clone o repositório.
3. Abra a pasta do projeto no Visual Studio Code.
4. Abra o arquivo `index.html` no navegador.
5. Explore a página e conheça o projeto!
